# Private local vault core
The shared module implements AES-256-GCM authenticated encryption, unique 16-byte salt and 12-byte IV for every save, PBKDF2-SHA256 (600,000 iterations), scope-bound authenticated metadata, 2 MiB plaintext cap, bounded strict backup parsing, and separate IndexedDB ciphertext records for business and personal. Keys are not exported or persisted. No server or hosted inference is involved.
This is a core library, not yet a live storage feature. UI integration must validate each workspace's schema, require explicit save/restore confirmation, clear passwords after use, disclose that loss of passphrase means no recovery, and offer encrypted export/import/delete. A locked vault does not encrypt an open workspace's memory; this does not protect against malicious browser extensions, compromised JavaScript, device malware, or weak passwords. Browser storage may be cleared or evicted. Unit tests use synthetic records only; browser storage lifecycle tests and actual user-device UX remain mandatory before enabling storage.

## Business profile integration
The business workspace now offers explicit Save encrypted profile, Restore saved profile, Export encrypted backup, Restore encrypted backup, Lock and clear open profile, and Delete saved encrypted profile controls. Restore validates and replaces only the business profile schema; supplier searches, quote scenarios, private feedback and model prompts are not persisted. Saved copy and open profile are distinct; deletion of one does not silently destroy the other. Browser lifecycle QA is required before merge. 

## Personal profile integration
Personal Intelligence uses the same encrypted vault with a distinct personal scope. Eight validated household fields may be saved locally by explicit consent; raw files, reviewed document records, account credentials, scenarios and prompts are excluded. Lock clears open profile and document state but does not change the encrypted copy or optional server monitoring. Backup restoration is schema validated and does not overwrite stored ciphertext unless explicitly saved. Personal and business envelopes cannot be interchanged. Browser tests gate the release.
