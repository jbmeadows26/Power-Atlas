# Shared Adaptive Intelligence Engine
## Implemented in v1
Business Intelligence and Personal Intelligence share the same optional client-side model. Standard mode is always available and uses deterministic keyword matching. The user supplies a priority/question and ranks existing findings (maximum 24); the local model returns IDs and semantic similarity only, never new evidence, facts, risk probabilities, financial predictions, or actions. The original evidence remains accessible in Decisions. This is an English semantic retrieval model, not a generative LLM or document-extraction model.
## Runtime
Transformers.js 3.8.0; Xenova/all-MiniLM-L6-v2 q8 pinned to cb3d680149bf9a3209564e1b27ab3bb355b65707, verified ONNX SHA-256 afdb6f1a0e45b715d0bb9b11772f032c399babd23bfc31fed1c170afc848bdb1. Model card lists Apache-2.0. Package and model files are built into the same Pages artifact, including license notices; actual download size is read from manifest. Build dependency resolution and redistributed transitive notices still need commercial supply-chain review. Model assets never load before explicit consent. Browser capability check reports WebAssembly, WebGPU and reported memory without claiming unreported memory; v1 runs CPU/WASM in one worker with one thread. WebGPU is detected but not enabled. Local model stops on reset or explicit standard-mode switch. Private queries and existing evidence are kept in tab/worker memory. The worker permits only fixed GET model assets during initialization, then disables its fetch path before private input; there is no hosted fallback. HTTP browser caching may retain public model assets, not user inputs. Offline inference after initialization is tested; offline startup/reloading is not implemented.
## Release
Real Chromium and WebKit inference, consent rejection, offline ranking, source-ID validation and privacy regression are required. Emulated viewport tests do not establish physical iPhone/Android performance, thermal impact or memory limits. Generative reasoning (WebLLM), browser-native AI, offline-first startup, broad document analysis and additional model tiers are future phases. The shared public-data Free Model Gateway remains separate and never receives private queries.

## Shared persistence scope
Encrypted local profile vaults are implemented separately for Business and Personal Intelligence. This does not persist model state or enable background inference when the browser is closed. Vault implementation and recovery tests are in `site/private-workspace/` and `tests/private-vault*`.

## Device modes and measured selection

The mode panel distinguishes Standard deterministic computation, optional Adaptive MiniLM q8, and unavailable Performance/Advanced tiers. Hardware detection alone never marks a generative model operational. Actual initialization and query latency are measured in the current browser session. A sub-5-second completed local query, compatible runtime and data-saver disabled can recommend Adaptive; this recommendation never downloads a model or changes modes automatically. Memory reports are device capacity, not free memory; runtime failure still returns to Standard. Performance and Advanced remain unavailable pending implementation, license/memory review and browser acceptance.
