# Personal Intelligence — evidence-first release candidate
Separate static frontend: site/personal-intelligence/. The existing Pages workflow publishes site/**; no modification to either existing application or collection job is required.
 
## Data and analysis
Reads five allowlisted public JSON records from the default branch of the existing repository. Refresh on load, manually, and every five minutes while the tab is visible. Public requests contain no profile data. Dates are observation dates; no claim of independent source verification or current quote. Failed requests remove that feed from calculations and display unavailable. No arbitrary priority, savings, forecast or risk score. Current analyst logic is deterministic, not model-based. The private backend now has an hourly deterministic monitoring job for explicitly opted-in saved profiles. It matches household, telecom, fuel and employment context; it does not send any profile to an external model. The monitoring UI stays disabled with authentication until API verification and signup delivery are validated.

## Private account activation
A dedicated Supabase project is required. The dedicated project has been provisioned. On a fresh project apply backend/profile-schema.sql followed by backend/private-monitoring.sql, enable email/password auth with email confirmation, and ensure REST Data API grants are effective. Configure email delivery, sign-up abuse prevention, recovery, session lifetime, and account deletion policy. Add site/personal-intelligence/auth-config.json containing only the dedicated project HTTPS origin in url and a public sb_publishable_ key in publishableKey. Never commit an elevated key. Do not enable configuration before testing two unrelated accounts and an anonymous client; verify select, insert, update and delete cannot cross account boundaries, expired sessions fail, and no private record is stored in public artifacts. Sessions remain in browser memory and require sign-in after reload. Guest profile is tab-only; export downloads user-entered data, save is opt-in. Deleting profile is not deleting account. Full account deletion and password recovery require further implementation.

## Production gates
Run node --test tests/personal-intelligence.test.mjs; verify mobile and desktop actual rendering and CORS; ensure existing Pages workflow passes. Authentication is disabled until provisioning and end-to-end security checks pass. Model-backed specialists, public account activation, additional data integrations and independent upstream validation remain outside this candidate. Do not claim they are running. No bank or health integrations in this release.

## Local document import
Open Profile → Import documents. Supported: text PDFs (locally packaged PDF.js 5.4.624), TXT, explicitly labeled field/value CSV, existing numeric profile JSON, and pasted text. Up to 10 MB, 50 PDF pages, 300,000 extracted characters. Individual bill amounts, statement balances and renewal/due dates remain document facts and never become aggregate household spending. All candidates require explicit selection; replacing an existing profile value requires confirmation. No OCR, transaction reconciliation, external account OAuth or AI extraction in this version. The app retains confirmed facts in tab memory only; raw document and extracted text are discarded on confirmation. Removing a reviewed document does not undo previously confirmed profile fields; Clear this tab resets both. No imported documents are uploaded, no raw text enters storage, and profile persistence remains disabled until the separate authentication gate passes. Local PDF vendor files are built into the release artifact, not fetched from a CDN at runtime. Tests use synthetic fixtures only.

## Local OCR expansion
JPEG, PNG and WebP photographs and image-only PDF pages use pinned Tesseract.js 6.0.1, WASM core 6.0.0 and English language model 1.0.0, hosted with the site. No runtime third-party OCR downloads, remote recognition or persistent OCR cache. A PDF with selectable text uses its text layer; empty pages fall back to OCR. Force OCR for mixed or unreliable text layers (at most 10 pages). Files remain capped at 10 MB; image decoding limited to 40 megapixels and recognition scaled to at most 5 megapixels. Recognition can be cancelled by discarding or changing the source. All values remain unselected candidates with explicit OCR warnings and require verification against the original. HEIC, handwriting, arbitrary languages and automatic bank transaction reconciliation are not supported. Tests exercise real OCR using synthetic image and scanned PDF fixtures only.
