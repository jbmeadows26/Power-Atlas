# EA-010 / EA-011 narrow benchmark forecasting

The fixed method predicts the World Bank monthly Brent benchmark two observation months ahead using the last three monthly observations' arithmetic mean. It is an experimental public input-cost benchmark, not a company cost, delivered fuel quote, shortage probability or optimized trading model. No model selection was performed on the held-out origins.

At initial execution on 2026-11-27, the official World Bank workbook was fetched with an identifying User-Agent, parsed through the existing collector, and its retained 36 monthly observations exactly matched the input. The raw workbook SHA-256 and retrieval date are recorded. A prior request without the identifying header returned HTTP 403; no fallback was promoted. Future primary retrieval failure or mismatched original history withholds issuance.

Initial forecast: December 2026, $110.90/bbl. Walk-forward evaluation starts after 12 observations and predicts two months forward at each of 23 origins. MAE is $12.884/bbl, versus $12.657 for the last-observation persistence baseline. **This method does not beat persistence.** The descriptive 80th-percentile absolute historical error radius is $26.967, not a calibrated confidence interval. Full per-origin predictions, observations and errors are published.

Chronological training slices prevent future values entering predictors. Nevertheless this is evaluation on a revised present-day dataset, not an archived vintage simulation: original historical publication dates and release lags are unavailable. This limitation prevents a claim of validated real-time historical skill. Prospective outcomes are pending. Only the narrow computational forecasting workflow is implemented; EA-010 is not complete.

Issued records include exact input history, hash, model version, target, forecast, baseline, uncertainty method, limitations and invalidation conditions. The JSONL ledger only appends hash-chained events. Resolved targets append actuals and both model/baseline errors; failed forecasts are retained. Repeated execution with unchanged input retains the original issue timestamp. Git history and hash chains expose accidental modifications; this is not a claim of tamper-proof independent custody. Revisions to an already resolved observed outcome currently require an explicit additional versioned event implementation; historical outcomes are not overwritten.

Daily GitHub Actions execution validates the original source and records events without private information or inference services. Concurrent main updates cause push failure rather than overwrite. Source freshness and future target checks withhold invalid issuance. The business homepage displays the evaluated benchmark, limitations and source, without using private inputs in fetches. It is relevant only when the customer declares a fuel dependency; supplier quotes and contracts remain necessary before procurement decisions.
