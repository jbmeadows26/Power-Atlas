# Power Atlas — comparative chart rules (V6)

**Purpose:** make an evidence-backed difference understandable on a small screen without exaggerating it.

1. **Comparison first.** Use horizontal bars for values across places, companies, years or populations. Sort rankings by the observed value when order is not intrinsic.
2. **Same ruler.** All values *within a comparison* share an explicit zero baseline and the same axis and units. Never divide by the largest observed value and then visually suggest that the largest value is 100%.
3. **Label every mark.** Display the category name and original value (including %/USD/time units) at the end of each bar. Show at least 0 and the scale maximum; a midpoint helps on narrow screens. Keep a visible U.S. benchmark when verified from the same period and measurement definition.
4. **Percentages ≠ percentage points.** Show differences between two shares as percentage points. Do not mix shares of transit commuters, SNAP households and uninsured people as if their denominators or concepts were the same. Each is a *separate* comparison.
5. **Geographic precision.** ZIP/ZCTA, city, metro, state and national measures have different coverage. Never present citywide asking rents or a metropolitan commute statistic as a precisely measured ZIP estimate. Keep source, geography, reporting period and denominator clear.
6. **Missing means missing.** If source values or a comparable U.S. benchmark are unavailable, show unavailability; do not invent reference percentages or interpolate.
7. **Mobile layout is deliberate.** Prefer full-width horizontal bars with exact value labels over two-up miniature charts at narrow breakpoints. Keep labels 11–13px+ when possible; verify 390px and 320px for overflow, clipped values, and taps.
8. **Accessible interpretation.** Charts expose an accessible sentence with units, both values and axis range; direct on-screen values must not depend on color distinction.
9. **Unit scales.** Use sensible rounded ceilings above the observed maximum, never a cropped origin for magnitude bars. A focused per-metric axis is acceptable *within a card* if labeled, but do not rank the heights of different cards as if they share an axis.
10. **Evidence preserved.** Chart redesign changes presentation, not the underlying numerical source, historical period or denominator. Retain direct source links and limitations.

That chart measures **commute duration**; Power Atlas's current local transportation metric measures **public-transit usage**. Those are different measurements and must not be substituted.
